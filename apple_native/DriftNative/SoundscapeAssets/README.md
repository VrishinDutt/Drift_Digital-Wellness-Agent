# Soundscape Assets

This folder holds tiny local placeholder audio files for internal Drift Native prototype testing.

Asset rules:
- Audio must be original, CC0, royalty-free with compatible redistribution rights, or explicitly licensed for this use.
- Do not copy Endel assets.
- Do not download, bundle, transcode, or derive Apple Music content.
- Do not use cloud streaming or cloud soundscape generation.
- Keep playback local-only and user-initiated.
- Keep placeholder files small until the app has a real asset pipeline.

Current placeholder:
- `breathing_cue.wav` is generated locally by `generate_placeholder_audio.py` using only the Python standard library.
